# 감정 챗봇 인지 기능 구현

## 인지기능 - 시각, 청각

---

## 1. 영상 기반 감정 인식 모델 (이미지 -> 감정)

- **모델**: [DeepFace](https://github.com/serengil/deepface)  
- **목적**: 사용자의 발언과 함께 얼굴 표정에서 나타나는 감정 정보를 기록하여 대화 맥락 강화  
- **분류 클래스**:  7개의 감정
  - `angry`, `disgust`, `fear`, `happy`, `sad`, `surprise`, `neutral`  

### 구현 전략
- 모든 프레임을 추론할 필요 없음 → 서비스 목적상 시스템에 부하가 없는 한도 내에서 일정 간격의 **프레임 샘플링** 적용  
- 성능과 효율성 균형을 위해 **일정 간격으로 추출한 프레임만 분석**  
- 단, Face Detector는 **RetinaFace**를 활용 (강건한 성능 확보)  

---

## 2. STT (Speech-to-Text) 모델 (음성 -> 텍스트)

- **목적**: 영상 기반 감정 인식 정보와 결합하여 LLM 활용  
- **필요성**: 스트리밍 방식이 아닌 자체 STT 과정 구현  

### 비교 방안
1. **Local 모델 (Whisper 등)**  
   - 장점: 외부 비용 없음, 오프라인 가능  
   - 단점: 제한된 연산 리소스로 인한 느린 추론속도  

2. **API 활용 (GPT API, CLOVA API 등)**  
   - 장점: 빠른 추론, 구현 용이  
   - 단점: 외부 서비스 의존성, 비용 발생  

👉 모델 추론 실험 후, 정확도와 추론 시간 간 **Trade-off 고려 결과: GPT API 활용이 적합**  

---

## 3. STT 구현 방법

### 방법 1. 시간 단위 요청 (deprecated)
- **설명**: 오디오를 일정 시간 단위(예: 15초)로 잘라 API 요청  
- **문제점**: 발화가 잘려 의미 손실 발생  
  - 예: “오늘은 날씨가 정말 …” → “오늘은 날씨가 정말”  

---

### 방법 2. 발화 단위 요청 (권장)
- **설명**: 쉼표(,), 마침표(.) 등 **호흡 단위**를 기준으로 API 요청  
- **장점**:  
  - 의미 단위가 잘리지 않으며, 정보 손실 최소화  
  - 짧은 구간 단위 요청 → 추론 시간 단축  
- **단점**:
  - 짧은 발화 단위로 인해 드물게 부정확한 전사(Transcribe) 발생

#### VAD (Voice Activity Detection) 활용
- 음성/비음성 구간 탐지 후, **발화 종료 + 침묵 시간 경과 시 API 즉시 요청**  


### 시스템 구성

- 음성인식 thread : 입력되는 음성을 연속적으로 기록하고 저장하는 역할
- VAD thread : 비음성 구간 지속적으로 모니터링하고, 탐지 즉시 API 요청 역할
- STT thread : GPT API로부터 전사된 텍스트를 요청하고 받는 역할



##### VAD 하이퍼파라미터 예시
```python
# VAD Parameters
VAD_AGGR = 3               # (0~3) 민감도; 낮을수록 더 자주 음성으로 감지
VOICE_RATIO_MIN = 0.10     # 최소 음성 비율 (예: 0.10 = 전체 중 10%)
MIN_VOICE_MS = 1000        # 최소 음성 지속 시간 (1초 이상일 경우만 발화로 인정)

# Silence Timeout Parameters
SILENCE_TIMEOUT_SEC = 2    # 침묵이 2초 이상 지속되면 API 요청
EARLY_MIN_VOICE_MS = 300   # 조기 플러시 허용: 최소 0.3초
EARLY_VOICE_RATIO_MIN = 0.05  # 조기 플러시 시 최소 음성 비율



### 3. 주요 고려사항
	•	실시간 반응성: 너무 긴 API 지연 시 대화 몰입도 저하 → 발화 블록 크기 최적화 필요
	•	비용 관리: API 호출 빈도에 따라 요금 급증 가능 → 필요 시 Whisper 로컬 추론 병행 고려
	•	프라이버시: 얼굴·음성 데이터 저장 시 암호화·익명화 처리 필요
	•	멀티모달 학습 확장: 향후 표정+음성+텍스트 동시 입력으로 감정 분류 고도화 가능
    •	멀티모달 UI 경험: 음성 인식으로 대화를 개시하거나, 음성, 영상으로 사용자들을 각각 고유하게 식별
