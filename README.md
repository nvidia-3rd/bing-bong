# Bing Bong - 실시간 감정 분석 시스템

## 🎯 프로젝트 개요

Bing Bong은 Streamlit과 WebRTC를 기반으로 한 실시간 비디오/오디오 감정 분석 시스템입니다. 비동기 아키텍처를 통해 고성능 스트리밍과 실시간 감정 추론을 제공합니다.

## 🏗️ 아키텍처 특징

### 비동기 오케스트레이션
- **Streamlit WebRTC 기반**: 프론트엔드에서 실시간 미디어 스트리밍
- **비동기 아키텍처**: `asyncio`를 활용한 고성능 데이터 파이프라인

### 세션 관리
- **동적 오케스트레이션**: START 버튼 클릭 시 새로운 오케스트레이션 인스턴스 생성
- **세션 종료**: STOP 버튼 클릭 시 오케스트레이션 완전 종료 및 리소스 정리


## 🎥 비디오 프레임 처리

### 프레임 샘플링
- **10 프레임 단위 처리**: 연속된 비디오 프레임을 10개씩 그룹화하여 효율적 처리
- **JPEG 인코딩**: WebRTC 스트림에서 받은 프레임을 JPEG 형식으로 변환
- **실시간 전송**: HTTP 클라이언트를 통해 서버의 `/ingest/frame` 엔드포인트로 전송

### 감정 분석 파이프라인
```
WebRTC Stream → Frame Sampling (10fps) → JPEG Encoding → HTTP POST → Emotion Inference → Result Queue
```

## 🎵 오디오 처리

### 실시간 오디오 캡처
- **PyAudio 기반**: 고품질 오디오 스트리밍 및 캡처
- **~VAD~ (Voice Activity Detection)**: 음성 활동 감지를 통한 스마트 오디오 처리
- **WAV 누적**: 오디오 데이터를 WAV 형식으로 누적하여 서버 전송

### 오디오 분석
- **전사 서비스**: OpenAI API를 통한 실시간 음성-텍스트 변환
- **비동기 처리**: 오디오 업로드와 분석을 별도 스레드에서 처리

## 🔄 데이터 플로우

### 클라이언트 사이드
1. **WebRTC 스트림 시작**: 사용자 미디어 권한 승인
2. **프레임 캡처**: 비디오 프레임을 10개씩 그룹화
3. **오디오 캡처**: VAD 기반 음성 활동 감지
4. **데이터 전송**: HTTP를 통한 서버 전송

### 서버 사이드
1. **프레임 수신**: `/ingest/frame` 엔드포인트에서 JPEG 이미지 처리
2. **감정 추론**: 비디오 프레임 기반 실시간 감정 분석
3. **오디오 처리**: `/ingest/audio` 엔드포인트에서 음성 전사
4. **세션 관리**: 세션 시작/하트비트/종료 상태 추적

## 🚀 기술 스택

### 프론트엔드
- **Streamlit**: 대화형 웹 애플리케이션 프레임워크
- **WebRTC**: 실시간 미디어 스트리밍
- **PyAudio**: 고품질 오디오 처리

### 백엔드
- **FastAPI**: 고성능 비동기 웹 프레임워크
- **OpenAI API**: 감정 분석 및 음성 전사
- **비동기 처리**: `asyncio` 기반 고성능 파이프라인

### 데이터 파이프라인
- **큐 시스템**: 비동기 컴포넌트 간 통신
- **스트림 오케스트레이터**: 전체 데이터 플로우 관리
- **세션 매니저**: 사용자 세션 상태 관리

## 📱 사용법

### 시작
1. START 버튼 클릭
2. 웹캠 및 마이크 권한 승인
3. 실시간 스트리밍 시작

### 중지
1. STOP 버튼 클릭
2. 오케스트레이션 완전 종료
3. 리소스 정리

### 재시작
1. STOP 후 START 버튼 클릭
2. 새로운 오케스트레이션 인스턴스 생성
3. 완전히 초기화된 상태로 시작

## 🔧 개발 환경 설정

```bash
# 클라이언트
cd bing_bong/client
poetry install
poetry run streamlit run ui/main.py

# 서버
cd bing_bong/server
poetry install
poetry run uvicorn main:app --reload --port 8000
```

## 📊 성능 특징

- **실시간 처리**: 10fps 프레임 샘플링으로 효율적인 감정 분석
- **비동기 처리**: I/O 블로킹 없는 고성능 스트리밍
- **메모리 효율성**: 큐 기반 스트리밍으로 메모리 사용량 최적화
- **확장성**: 모듈화된 아키텍처로 기능 확장 용이
